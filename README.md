# 11月分進捗
## 操作方法
矢印横で移動。矢印上でジャンプ。  
Zで近接攻撃
Cで弾、長押しでチャージ弾(サイズとスピードが変わる)
スペースでローリング回避

## 今月の成果一覧
- 成果4:2段ジャンプ
  - ジャンプして空中にいるとき再度ジャンプできるようにしました
- 成果5:まっすぐ飛ぶ弾,チャージショット
  - Cでチャージショットを追加しました(長押しでチャージするとサイズが大きくなります)
- 成果6:デス演出
  - 自機がやられた時ロックマン見たいに飛び散る演出を追加しました(自機のHPは仮で5)
- 成果7:敵の遠距離攻撃
  - 敵が一定期間ごとに弾を飛ばしてくるようにしました
- 成果8:敵の地形移動
  - 壁に触れたりすると反応して自分でジャンプするようにしました
- 成果9:自機の攻撃判定の追加
  - 自機が近接または弾での攻撃に敵への当たり判定を追加しました(敵のHPは仮で3)

## その他
今月で大体自機のやりたい行動は実装できたので１２月中では敵の行動や演出をどんどん実装していき、もしいけそうならフィールドギミックにも挑戦したいと思っています。
特に敵の自機への追尾するような行動を優先して作っていきたいと思います。

# 10月分進捗
## 操作方法
矢印で移動。  
スペースでローリング
Zで近接攻撃
## 今月の成果一覧
- 成果1:自機の移動
  - キーボード、コントローラーで移動可能にしました(コントローラーはまだ移動のみ)
- 成果2:自機の近接攻撃
  - Zでの近接攻撃を可能にしました(描画のみ)
- 成果3:ローリング
  - スペースでのローリングを可能にしました(ローリング中は無敵)

## その他
ローリングの実装で少し悩んでしまいあまり多く実装できなかったので少しペースを上げていきたい
